Detailed Description

A database storing Tetra star patterns.

Layout: | size (bytes) | name | description | |-------------------------------------—+---------------—+---------------------------------------------—| | sizeof(decimal) | maxFov | max angle (deg) between any 2 pattern stars | | sizeof(int32_t) | numEdgeRatioBins | number of bins for edge ratio discretization | | sizeof(uint64_t) | patternTableSize | number of slots in pattern hash table | | sizeof(uint16_t) | tetraCatalogSize | number of stars in Tetra preprocessed catalog | | 4 * patternTableSize * sizeof(uint16_t)| patternTable | hash table of 4-star patterns | | tetraCatalogSize * sizeof(uint16_t) | catalogIndices | maps Tetra index to real catalog index | |-------------------------------------—+---------------—+---------------------------------------------—|
